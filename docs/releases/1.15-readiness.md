# tokmd 1.15 Release Readiness

Status: `v1.15.0-rc.1` release-prep candidate; container proof is green, but the candidate is not ready to tag. This document is the command-backed RC receipt and
must be updated with exact SHA, command result, and artifact links during
release preparation.

## Release boundary

- Target: `v1.15.0-rc.1`, followed by `v1.15.0`.
- Previous stable: `v1.14.0`.
- Preparation repository: `EffortlessMetrics/tokmd-swarm`.
- Publication repository: `EffortlessMetrics/tokmd`.
- Tagging, publishing, GHCR mutation, and Action alias movement occur only in
  the publication repository.
